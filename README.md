# Olá, eu sou a Gabriela 👋

🎯 Em transição de carreira para **Quality Assurance / Teste de Software**

Sou Engenheira Química, com experiência prévia em Assuntos Regulatórios, e decidi migrar para QA — a atenção a detalhes e o rigor de processo sempre fizeram parte do meu trabalho, e hoje aplico isso testando software.

Concluí a **Formação em Teste de Software e QA pela Iterasys**, com foco em testes manuais, testes de API, automação e práticas ágeis.

### 🔧 Tecnologias e ferramentas

- **Testes manuais:** planejamento de testes, casos de teste, teste exploratório, classes de equivalência e valor limite
- **BDD:** Gherkin e Cucumber
- **Automação web:** Playwright, WebDriverIO, Page Objects, JavaScript
- **Automação mobile:** Appium
- **Testes de API:** Postman, Playwright (request)
- **Documentação de QA:** plano de teste, matriz de rastreabilidade, report de bugs com evidências
- **Versionamento:** Git e GitHub
- **Metodologias:** Ágil (Scrum e Kanban)
